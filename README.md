# EduAgent AI

Sistema de atendimento educacional com Inteligencia Artificial.

## Tecnologias

- C# / .NET 10
- ASP.NET Core Web API
- SQL Server
- React / TypeScript
- OpenAI API
- xUnit
- Docker

## Arquitetura

- Domain: entidades e regras de negocio
- Application: casos de uso e contratos
- Infrastructure: banco de dados e integracoes
- Api: endpoints HTTP
- Tests: testes automatizados

## Objetivo

Desenvolver agentes de IA para atendimento
de alunos e professores, incluindo historico,
consultas de aulas e avaliacao das respostas.

## Status

Etapa 1: estrutura inicial.
